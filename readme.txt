ПРОЕКТ: Локальный ИИ-Агент прямого чтения (Direct-Read Agent) без RAG

АРХИТЕКТУРА И ПРИНЦИП РАБОТЫ: 

* Система работает по принципу «глаза и руки»: читает файлы целиком напрямую с диска.
* Полный отказ от векторных баз данных, эмбеддингов, RAG и Qdrant.
* 100% изоляция: работает полностью локально на ПК, без интернета и облаков.
* Защита от галлюцинаций: системный промпт запрещает ИИ использовать внешние знания.

Взаимодействие элементов:
[ Папка text_for_AI ]
▲
│ (Читает файлы напрямую через pypdf / open)
▼
[ Скрипт gui_agent.py ] ◄──► [ Веб-интерфейс Streamlit ] ◄──► [ Вы (Браузер) ]

│ (Официальный Python-клиент)

ПОШАГОВЫЙ МЕХАНИЗМ ВЗАИМОДЕЙСТВИЯ (FUNCTION CALLING):
Устроено по принципу пошагового диалога двух программ через вызов функций. Скрипт дает модели «глаза» и «руки», а модель говорит скрипту, что делать. 

• Шаг 1: Скрипт отправляет модели вопрос и список «инструментов»
Скрипт gui_agent.py берет ваш вопрос и отправляет его в Ollama, передавая паспорт инструмента — JSON-описание функции read_local_file.
• Шаг 2: Модель принимает решение (Умный стоп-кран)
Модель gemma4 анализирует вопрос. Понимая, что в памяти файла нет, она останавливает обычную генерацию текста и отправляет скрипту техническую команду: вызови функцию read_local_file для указанного файла.
• Шаг 3: Скрипт выполняет «грязную работу»
Скрипт идет в папку text_for_AI, физически открывает файл и считывает текст. В браузере отображается синяя плашка 🔍 ИИ читает файл...
• Шаг 4: Скрипт возвращает модели прочитанный текст
Скрипт упаковывает текст в сообщение с ролью tool и отправляет обратно модели.
• Шаг 5: Модель выдает итоговый результат
Модель формулирует красивый структурированный ответ (ИТОГ) на основе текста и отдает его скрипту для вывода в Streamlit.
